
# Coffee Shop Network Design

## Overview

A small-business network designed and simulated in Cisco Packet Tracer 9.0.1. This project explores network infrastructure, connectivity, segmentation, and security controls for a coffee shop.

## Objectives

- Design a functional small-business network.
- Configure IPv4 addressing and routing.
- Implement network segmentation and appropriate access controls.
- Verify connectivity and test security restrictions.
- Document troubleshooting and validation procedures.

## Network Architecture

The topology includes a multilayer switch, an ISP-facing router, office endpoints, printers, a point-of-sale terminal, and a wireless access point.

See `screenshots/01-topology.png` for the final topology.

## Technologies

- Cisco Packet Tracer 9.x
- Cisco IOS CLI
- IPv4 networking
- VLANs and routing
- Network access controls
